# Business Request — Workshop Feedback Portal

Our Learning & Development team runs internal technical workshops.

We need a simple web application where attendees can submit feedback after a workshop and organizers can review the responses.

The application is only a proof of concept. It should be inexpensive to operate and easy to deploy to AWS.

The business team has intentionally not specified the feedback fields, workflow details, API design, data model, or cloud architecture. Those should be clarified and designed through the SDLC process.
